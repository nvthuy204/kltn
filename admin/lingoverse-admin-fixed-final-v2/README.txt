Cách chạy:
1. Giải nén file zip.
2. Mở index.html bằng Chrome.

Đã sửa đúng các lỗi đã báo:
- Bỏ hoàn toàn header/tab trong trang Bài học.
  Không còn dòng: Tất cả bài học / A1 / A2 / Thêm bài học.
- Thêm bài học là trang riêng, mở từ sidebar hoặc nút + Thêm bài học.
- Modal Import Excel:
  + Bấm Hủy sẽ đóng modal và quay lại đúng trang trước đó.
  + Bấm X sẽ đóng modal và quay lại đúng trang trước đó.
  + Bấm ra nền ngoài modal cũng đóng và quay lại trang trước đó.
- Checkbox trong bảng đã chỉnh về 15px, không bị phóng to.
- Bảng vinh danh đã sửa thành Viết Dũng.
- Lọc chạy thật:
  + Người dùng: tên/email, vai trò, cấp độ, trạng thái.
  + Từ điển: từ/phiên âm/nghĩa, cấp độ, trạng thái.
  + Bài học: tên/chủ đề, loại bài học.
  + Thi thử: tên/kỹ năng, trình độ, trạng thái.
- Giữ chức năng demo:
  + Thêm, sửa, xóa, xem chi tiết.
  + Khóa/mở khóa user.
  + Đổi trạng thái từ điển/bài học/bài thi.
  + Import Excel demo vào Từ điển.
