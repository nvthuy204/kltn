LINGOVERSE ADMIN CRUD + REPORT DEMO

Cách chạy:
1. Giải nén file zip.
2. Mở index.html bằng Chrome.
3. Đăng nhập bằng thông tin đã điền sẵn hoặc nhập bất kỳ email/mật khẩu.

Bản này đã thêm:
- Trang Báo cáo.
- Các thao tác Chi tiết / Sửa / Xóa / Khóa hoặc Ẩn chạy thật bằng JavaScript.
- Modal chi tiết.
- Modal sửa/thêm dữ liệu.
- Modal xác nhận xóa.
- Thêm mới người dùng, từ vựng, cộng đồng bằng modal.
- Thêm bài học trong module Bài học.
- Thêm đề thi trong module Đề thi.
- Chi tiết bài học nằm trong module Bài học.
- Chi tiết đề thi nằm trong module Đề thi.
- Khôi phục dữ liệu demo bằng nút “Khôi phục dữ liệu”.

Các trang có demo lọc:
- Người dùng
- Từ vựng
- Bài học
- Đề thi
- Cộng đồng
- Báo cáo

Bộ màu dùng:
- Primary: #4A90E2
- Secondary: #6FCF97
- Accent: #F2994A

Font:
- Inter, fallback Arial/sans-serif.

Lưu ý: Đây là demo tĩnh phục vụ UI/UX, dữ liệu chỉ chạy trong trình duyệt, không có backend thật.
